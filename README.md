📊 E-commerce Sales Data Analysis (Excel Project)
📌 Overview

This project analyzes 31,000+ rows of e-commerce sales data to identify trends, customer behavior, and business insights.

🛠 Tools Used
Microsoft Excel
Microsoft Copilot (AI)
🔄 Process
Data Cleaning (handled missing values & duplicates)
Data Transformation (created month & customer segments)
KPI Analysis (sales, orders, behavior)
Dashboard Creation (pivot tables & charts)
